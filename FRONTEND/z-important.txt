Steps to build AuthContext

1. Create a context to hold auth state globally
2. Store user and accessToken in state
3. Create a login function that calls the backend
4. Create a logout function that calls the backend
5. On app load, check if user is already logged in
   by attempting a token refresh
6. Wrap the app with the context provider
   so all components can access auth state



AuthProvider — the clean wrapper
AuthContext.Provider — the box filled with values
AuthContext — the empty box
useAuth — the key to open the box



**In simple terms:**
- `AuthContext` — the empty box
- `AuthContext.Provider` — the box filled with values
- `AuthProvider` — a clean wrapper that contains all the logic and the filled box inside it

So the relationship is:
```
AuthProvider
    └── contains AuthContext.Provider
            └── which fills AuthContext with values









Steps to build App.jsx

1. Wrap the whole app with AuthProvider
   so all components can access auth state
2. Set up react-router-dom for navigation
3. Create a ProtectedRoute component that
   blocks unauthenticated users
4. Create an AdminRoute component that
   blocks non-admin users and redirects
   them to their dashboard
5. Define all routes and assign the correct
   protection to each one







   Steps to build Login.jsx

1. Create a form with email and password fields
2. On submit, call the login function from useAuth
3. If login succeeds, check the role and redirect
   - ADMIN → /admin/dashboard
   - IT_INTERN → /dashboard
4. If login fails, show an error message
5. Add dark mode support




Steps to build Admin Dashboard

1. Fetch all logs from the backend on page load
2. Fetch all users from the backend on page load
3. Display summary cards
   (total logs, total users, solved, unsolved)
4. Display a table of all log entries
5. Each log row has a delete button
6. Add Navbar at the top
7. Add dark mode support



Steps to build Navbar

1. Show the app name/logo on the left
2. Show the logged in user's role on the right
3. Show a logout button
4. Add dark mode toggle button
5. On logout, redirect to login page




Steps to build Delete Confirmation Modal

1. Create a modal component that accepts
   isOpen, onClose, onConfirm as props
2. Blur the background when modal is open
3. Show a warning icon and message
4. Have a passcode input field
5. On confirm, pass the passcode back
   to the parent component
6. Close modal when X button is clicked
7. Close modal when Cancel is clicked
8. Add dark mode support




Steps to build Admin Users page

1. Fetch all users from the backend on page load
2. Display users in a clean card or table layout
3. Each user shows name, email and role
4. Each user has a reset password button
5. Each user has a delete button (with confirmation)
6. Add a button to navigate to create user page
7. Add Navbar at the top
8. Add dark mode support






Steps to build Create User page

1. Create a form with name, email and password fields
2. On submit, send request to backend with
   admin token and passcode in headers
3. If successful, redirect to admin users page
4. If failed, show error message
5. Add Navbar at the top
6. Add dark mode support




Steps to build CreateLog page

1. Create a form with all log entry fields
   (department, personWithProblem, problem,
   solution, solvedBy, status)
2. On submit, send request to backend
   with access token in headers
3. If successful, redirect to correct
   dashboard based on role
4. If failed, show error message
5. Add Navbar at the top
6. Add dark mode support






Steps to build Intern Dashboard

1. Fetch only the logged in intern's logs
   from the backend on page load
2. Display summary cards
   (total logs, solved, unsolved)
3. Display a table of the intern's log entries
4. Add a button to create a new log entry
5. Add Navbar at the top
6. Add dark mode support
